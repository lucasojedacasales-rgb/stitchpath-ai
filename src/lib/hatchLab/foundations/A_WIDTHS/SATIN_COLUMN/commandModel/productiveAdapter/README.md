# P1.F2 isolated productive command adapter

Version: `P1.F2-A_WIDTHS-STRAIGHT-SATIN-PRODUCTIVE-COMMAND-ADAPTER-V1`.

This pure Hatch Lab adapter represents each valid P1.F1 straight-satin segment as one object using
the audited pre-CE01 productive command core:

```js
{ type: "stitch", x, y, regionId }
```

`x/y` are the unchanged absolute-mm destination `toMm`; no rounding, quantization, subdivision,
filtering, or reordering occurs. `startAnchorMm` remains a separate `startAnchor` and does not add a
command. The classification is
`PRODUCTIVE_MM_CONTRACT_REQUIRES_START_ANCHOR_ADAPTER`.

## API

- `adaptLabSatinCommandsToProductiveShape({ labCommandModel, targetContract, options })`
- `validateProductiveShapeCandidate({ candidate, labCommandModel, targetContract })`
- `recoverLabPathFromAdaptedCommands({ startAnchor, productiveCommands, targetContract })`
- `canonicalizeProductiveShapeCandidate(candidate)`
- `computeProductiveAdapterHash(candidate)`

Invalid source models return diagnostics with empty `productiveCommands`; they are never repaired.
The field map excludes `color`, `stitchType`, `source`, `layerType`, `metadata`, `objectId`, and
encoder deltas because P1.F1 cannot supply those values authoritatively.

The fixtures and reports in this directory are generated by the adapter API from the five persisted
P1.F1 fixtures. They are shape-compatible candidates only:
`candidateOnly: true`, `integrated: false`, `machineReady: false`, `exportReady: false`,
`ce01Validated: false`, `encoderValidated: false`, `physicallyValidated: false`.

Nothing here is connected to `flattenToCommands`, `buildFinalCommands`, CE01, a simulator, an
encoder, or an exporter.
